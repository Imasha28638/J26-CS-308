# Member 2 — PP1 research results

The JSON/CSV reports in this directory are selected aggregate evaluation artifacts copied from the original research workspace. They are **not** raw AWS CloudTrail event datasets.

Comparisons must distinguish data sources and validation methods: the mixed-source experiment is exploratory, the publisher's test split is not fully actor-disjoint, and the public-dataset out-of-fold checks have very few independent positive groups. Neither the stacking ensemble nor its class-weighted candidate consistently outperforms LightGBM on the labeled public data. Original datasets and detailed per-record audit tables remain outside this repository.
